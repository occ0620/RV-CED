# v4 内容对齐可行性核查

本核查只读取冻结清单和标签元数据，不使用模型预测、不选择新供体、不修改阈值。精确同句按去除标点和空白后的文字相等定义。

| 模态 | 候选范围 | 30源中有其他同句片段 | 有同向候选 | 有反向候选 | 可提供两组同/反候选 |
|---|---|---:|---:|---:|---:|
| A | same_test_split | 0 | 0 | 0 | 0 |
| A | all_splits | 0 | 0 | 0 | 0 |
| V | same_test_split | 0 | 0 | 0 | 0 |
| V | all_splits | 0 | 0 | 0 | 0 |

这些数量只回答是否存在最低限度的同句候选。音频仍没有词级时间对齐或说话人控制；视频仍没有身份或口型同步保证。

文本 T 若只替换文字但保留原语音，要保持语词一致只能使用相同文字，这不再构成文本情感干预。视频 V 即使文字相同、时长相近，也不能证明嘴型逐时刻对应。

因此，只加强现有供体筛选不能完整修复 T/A/V 同步。需要改变研究问题，或创建具有同一内容、同一身份和时间对齐的受控材料，并作为新 v4 重新推理。

## 建议的修复决定

1. 将 `main-a800-v3` 冻结保存并改称“跨模态冲突/通道替换探索”。它可以描述模型对不一致输入的响应，不能估计纯情感通道效应。停止尚未完成的组合盲审；已完成的单通道评分保留为供体标签关系诊断。
2. 不再为 v3 重配供体或修改筛选阈值。精确同句候选为 0，继续调时长、字符数或标签阈值不能解决语词和口型问题。
3. 如果坚持自然真实材料、不使用合成数据，做一次小规模 v4“自然冲突评测”：只用每个原始片段自身同步的 T/A/V，预先按数据集 T/A/V 标签冲突结构抽样；比较完整同步输入与预定的目标通道缺失输入。该设计回答目标通道对自然样本判断的增量，不宣称情感反事实或供体替换因果效应。
4. v4 必须使用全新冻结清单、配置、缓存和报告；在查看新模型输出前固定样本与条件。第一阶段不训练、不做 LoRA。规模保持小且一次性，不扩展成多轮消融。
5. 如果研究问题必须是“同一句话、同一身份、只改变一个通道的情感”，CH-SIMS v2.0 现有原始片段无法提供。需要另行采集同一说话人对同一句话的多情感表演并做时间对齐，或使用生成/编辑材料。后者属于合成刺激，必须单独标记，不能替代真实实验。

推荐采用第 3 项作为唯一一次针对性 v4；它保留真实同步输入，并直接承认回答的问题从人工反事实变成自然冲突下的模态增量。若不接受问题变更，则本项目应在 v3 停止扩大，而不是制造“看似同步”的组合。

按原 `tau=0.2` 对 1,005 个可用测试片段作未使用模型输出的计数：目标模态与另外两个非中性模态方向相反的严格自然冲突，T 有 18 条，V 有 17 条，A 为 0 条。因此一次小规模 v4 可在查看新输出前分别从 T、V 候选中固定最多 12 条；A 在这一严格设计中暂停，不放宽定义凑样本。该数量只是可行性计数，正式 v4 仍需先冻结完整纳排与条件。
