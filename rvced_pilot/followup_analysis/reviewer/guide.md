# 独立盲审字段说明

关系审核待完成。两位审核者分别填写自己的表，不讨论、不查看对方评分，不看标签、模型输出或私有映射。
只使用专用盲审服务。不要在项目根目录启动通用文件服务器。

页面分两步。先完成独立通道评分、导出保存，再进入组合输入。逐项ID与CSV逐行对应，可调整行序，不能删行、改ID或改stage。
出现重复内容仍独立填写；备注可记“疑似重复”。展示次数不代表独立证据数量。
浏览器只在本机保存临时进度，没有自动提交；每次离开前点击“导出当前评分CSV”，保留原文件的不同版本。
两位审核者应使用不同浏览器配置或不同设备；同一浏览器的历史内容不应成为另一人的参考。

## 第一步：channel，180项

仅根据所展示的独立通道判断，不补看其他通道。

| 字段 | 填写方法 |
|---|---|
| reviewer_id | 一人一个固定ID，两人不同，整张表保持相同 |
| polarity | -1负向、0中性、1正向；不能把无法判断直接当中性 |
| intensity | 0无、1弱、2较弱、3较强、4强 |
| confidence | 1低、2中、3高；这是人的判断信心，不是模型概率 |
| clarity | 1难以辨认、2受限但部分可辨、3清楚；无法判断用unknown |
| speech_words_understood | 音频用1能理解词义、0不能理解、unknown不确定；其他通道na |
| subtitles_present | 视频用1存在字幕、0未见字幕、unknown不确定；其他通道na |
| subtitles_readable | 视频有字幕时用1可读、0不可读、unknown不确定；字幕不存在用na；其他通道na |
| 六种问题字段 | 第一步留空，第二步填写 |
| notes | 记录模糊、无法判断、字幕只部分可读等；不要补入外部标签 |

音频是完整语音，**没有模糊语词**；按实际听到的全部内容判断，不能假装只听纯韵律。
视频仅有8个均匀无声帧，字幕未知不能当成没有字幕，不能据此充分验证唇音同步。
如果极性确实无法判断，保留该格空白并写备注；表会被标为未完成，不会擅自插补、判为关系通过或生成完整高质量子集。

## 第二步：combination，180项

独立查看当前组合的文本、完整语音和无声画面。polarity/intensity/confidence留空；clarity及三个可理解性/字幕字段填na。
六个问题字段均用0无明显问题、1有明显问题、unknown证据不足；不得用0代替未知。

| 问题字段 | 本次固定的操作说明 |
|---|---|
| processing_error | 明显损坏、静音/黑帧、错误缺通道、异常重复或解码错误；跨通道情感不同本身不算处理错误 |
| speech_content_conflict | 可理解语词与独立文本有明显语义不一致；仅语气/情感不同不自动当成语词冲突；听不懂或信息不足用unknown |
| subtitle_leakage | 可读字幕/画面文字提供了词义或情感线索；不确定是否可读或能否提供线索用unknown |
| identity_discontinuity | 能由展示本身辨认的身份不一致或跳变，如人声/人物身份明显不一致；无法判断用unknown |
| scene_discontinuity | 能由展示本身辨认的场景不一致或跳变；无法判断用unknown |
| timing_discontinuity | 明显时间/同步问题；8帧不能充分判断唇音同步，没有足够证据用unknown |

界面没有原始参照，若“相对原始源的身份/场景变化”无法从单项确定，必须填unknown，不要猜成无变化。
这些字段的细化解释和新增清晰度/词义/字幕字段是本轮事后准备，在打开人工评分前固定。
它们只增加描述信息，不把新条件偷偷加入原先的关系或高质量判定规则。

导出的表应含360行。审核人员只交自己的CSV，不合并、不自行裁定分歧；分析程序会保存两份独立原始表及分歧记录。
