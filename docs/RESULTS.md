# 已有结果复核与效应分解

标签规则构造，关系审核待完成。公开结果是实际缓存的汇总，未新增推理、训练或消融。

## 单位与原定义

每模态30个源、每源2组供体。先在每组三元组计算delta_A、delta_B和D，再源内平均两组，最后跨源等权。
B正/零/负比例与A类别稳定率是先计算每组指示值再源内平均；本次等价60个三元组的比例。
供体符号一致率以30个源为分母。对源平均delta_B再判正负是另一个事后指标，不能替代原B正向比例。
主零容差1e-6；源强度≥0.4，方向d=−sign(目标CSV标签)，不是由模型决定。
均值保留原主指标；中位数、逐源移除与A/B配对分解均标为事后探索。所有区间为2,000次源聚类描述性95%区间。
重采样保持同源全部模态和两组供体，不声称充分处理供体复用或任意供体选择的不确定性。

## 供体稳定性与源影响

delta_A符号一致率三个通道均25/30；delta_B为T29/30、A24/30、V29/30；D为T17/30、A21/30、V25/30。
V的D两组幅度Pearson仅0.126，平均绝对差0.329；高方向一致率不意味着幅度稳定。
D>0但delta_B≤0有9个三元组；源内平均后6个源×模态单元、5个不同源。不能混用统计单位。
逐一移除源后D均值范围T[0.110,0.135]、A[0.209,0.242]、V[0.302,0.333]，均仍为正；这不验证关系或协议。

## 结构和边界

30源中27个T/A/V/整体极性全一致，3个部分冲突；目标模态唯一与整体一致的源为0。
原预测负13、中性2、正15；候选内max(p)≥0.9仅4源。候选分数不是校准概率。
仅原视频ID有可靠元数据，身份、场景、字幕、语言、录音环境和语词冲突未知；unknown不能当作已匹配。
CSV和特征pickle标签版本存在既有差异，本轮事前固定CSV；旧test已探索过，不称新盲测。
完整语音含语词，视频字幕未知，不能解释为纯韵律或纯面部表情效应。
预设分层与小格标记见[strata.csv](../rvced_pilot/followup_analysis/tables/strata.csv)，<10源只报数量。

## 结论分层

- 已有缓存支持：固定输入通道替换有可测响应，A对照也移动，D模态差主要伴随A差；供体符号与幅度稳定性不一致。
- 必须等待人工：关系、强度、身份/场景及处理质量、字幕/语词干扰、高质量子集和协议有效性。
- 需要第二模型或新实验：跨模型/任意供体推广、超出自然冲突评测的增量信息、纯通道信息分离和未覆盖冲突结构。

当前不建议训练或启动第二模型。只有关系可靠、供体选择下仍稳定、且体现超出自然冲突评测的信息后，再讨论第二模型。
若人工发现协议问题，仅按该问题与数据条件预设一次小规模v4，不依据已有预测或D挑有利样本。
